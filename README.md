# 第五人格区域选择模拟器

《第五人格》（Identity V）赛事**地图区域选择 / 密码机分布模拟器**——单文件网页工具，浏览器打开即用，无需安装。

## 主要功能

- **9 张比赛地图**：军工厂、圣心医院、红教堂、湖景村、月亮河公园、里奥的回忆、永眠镇、唐人街、不归林
- **密码机组切换**：每张地图内置 5~6 组密码机分布，用 `‹` `›` 按钮或圆点切换，地图与点位同步更新
- **区域选择模拟**：
  - 求生者最多选择 4 个区域，监管者选择 1 个区域，点击地图上的区域框即可选择/取消
  - 双方选择互斥（一方已选区域另一方不可选）
- **封禁密码机自动判定**：监管者选定区域后，自动找出距离该区域中心最远的密码机并高亮（琥珀色虚线圆圈），面板同步显示名称与像素距离
- **密码机分析面板**：列出当前组全部 7 台机的编号、名称、刷机特点、像素坐标；自动高亮最远机（金黄）与封禁机（琥珀），点击行可在图中绿色高亮对应机点
- **战术提示**：内置每张地图的密码机分布规律（固定提示）与当前组的战术建议（动态提示）
- **宝箱分布模式**：点"宝箱位置"按钮，地图整图切换为 WIKI 宝箱点位俯视图（每图一张），方便查看宝箱刷点；区域选择在该模式下依然可用
- **其他**：一键重置选择、深色主题、窗口缩放自适应、窄屏上下堆叠布局

## 使用方法

1. **打开**：用 Chrome / Edge 等浏览器直接打开 `第五人格区域选择模拟器_20260809.html`（需联网，地图图片在线加载）
2. **选地图**：点顶部地图卡片切换地图
3. **选密码机组**：用地图区上方的 `‹` `›` 或圆点切换分布组
4. **选阵营**：点"求生者 / 监管者"切换，然后**点击地图上的区域框**进行选择（再次点击取消）
5. **看结果**：右侧面板显示密码机列表、监管者位置、封禁机距离与战术提示；图中的金色圈为封禁机
6. **看宝箱**：点右上角"宝箱位置"按钮切换到宝箱分布图，再点一次切回
7. **重置**：点"⟲ 重置选择"清空全部选择

## 注意事项

- **必须联网**：地图图片、宝箱图片、字体均从网络加载；图片加载失败会自动重试
- 像素坐标以各 WIKI 原图为基准，仅供训练/复盘参考
